## 账号与准备

管理员首次使用本机环境生成的密码登录，立即修改个人密码。建立部门，再建立工程师、调度、仓库、经理及客户账号。内置角色不能改名或改变权限；需要不同权限时建立自定义角色。客户账号必须绑定有效客户，且只含客户权限。账号停用、部门停用、客户停用或密码变更会拒绝已有会话的后续业务访问。

角色权限决定左侧菜单和可执行按钮，后台再次核对每个接口。管理员可跨部门；其他员工限本部门。工程师的工单限指派给自己，客户只看绑定客户的资料与工单。主数据编辑需要当前版本，其他人已更新时刷新后重试。

## 设备服务

1. 客户管理建立客户，设备台账建立设备、序列号、位置和保修日期。不要录入真实个人隐私到公开学习环境。
2. 合同管理可为设备建立服务合同，填写起止日期与响应／解决小时数。创建工单时系统选取当前有效合同，优先选择结束日期更晚的合同。
3. 在服务工单点击新建，选设备，填写真实问题和优先级；客户由设备确定。合同或保修有效则保内，否则收费。
4. 收费工单由调度报价，客户登录后确认报价；保内工单直接派工。改动报价会重新要求确认。
5. 调度选择同部门有效工程师，工程师登录接单。等待备件或客户时记录原因，恢复后按实际等待时间顺延解决时限。
6. 工程师记录诊断、处理和实际工时，上传服务图片或PDF；完成安全和功能检查。附件不作为在线签名。
7. 完工前消耗实际使用备件并退回剩余数量。提交经理复核；复核可退回执行，批准后等待客户确认。
8. 客户确认关闭；经理登记已完成的收款凭证，保内零收费可登记核销凭证。登记不会发起支付。

取消工单需处理所有领用余量。关闭未结算工单可由经理重开并填写原因；已结算工单不可重开账单，应重新建立服务请求。服务请求目前没有专门的关联工单字段，可在说明中记录原工单编号。

## 备件与费用

先维护备件编码、单位和单位成本，库存初始为0；仓库执行入库和领用，工程师执行消耗，仓库执行退回。每次消耗／退回必须选择对应原领用流水，累计不能超出领用数量。

领用即减少库房库存，消耗核销已领数量并计入工单成本，退回增加库存。原领用时的成本为费用快照，不随后续主数据价格变化。复核、待确认、关闭或取消状态不可继续领料。重复库存请求使用相同幂等键时返回原结果，不重复处理。

默认人工费率120元／小时，部门系统参数`labor_rate`可修改，按实际工时分钟换算；已建立工单使用原快照。客户界面不显示内部成本。仪表盘“收费报价”仅累计已关闭收费工单的报价，不代表实际到账。

## 周期维保与知识

计划填写设备、下一日期、间隔天数和作业说明。后台每60秒检查到期计划，也可手动触发；每个日期只生成一次工单。每轮每计划最多追补30期，长期过期计划可能需要多轮。停用计划、设备、客户或部门后不生成新任务。生成后仍须人工派工与正常验收。

知识资料填写标题、分类和内容并发布。工程师在工单内输入查询词检索本部门已发布资料，本地规则按当前状态给出检查建议。该功能不调用模型，也不会执行操作。

## 字典、参数与导入

“字典与参数”维护故障分类参考值及三项实际系统参数：`labor_rate`、`response_hours`、`resolution_hours`，种类填写“系统参数”。默认响应24小时、解决72小时；有效服务合同覆盖默认时限。其他种类仅作为字典资料，不自动改变流程。

客户或备件批量导入使用JSON对象数组，每批1至100条，任一条失败整批回滚。示例仅用于独立学习测试：

```json
[{"name":"学习测试客户","site":"测试场地","contact":"学习资料"}]
```

```json
[{"name":"学习测试备件","sku":"STUDY-PART-001","unit":"件","unitCost":"25.50","enabled":true}]
```

导入不提供初始库存字段，库存仍由入库事务登记。工单导出按当前搜索词及状态筛选，最多5000条；超过时请细化筛选，暂不提供全量离线导出。
